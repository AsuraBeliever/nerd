# nerd

App web personal para organizar la universidad y el entrenamiento: horario escolar, tareas y exámenes por materia, pendientes personales, y registro de rutinas de ejercicio con seguimiento de progreso.

**Estado:** en planeación (Fase 0 de 9) · **Versión:** 0.0.1

## Stack

Next.js 15 · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Drizzle ORM · PostgreSQL (Neon) · Auth.js + Google · Vercel
